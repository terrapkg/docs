<Aside title="Macro Argument Syntax" type="tip">
  All macro flags followed by `<…>` REQUIRE an argument passed to them.<br />
  All macro flags followed by `[…]` MAY have an argument passed to them.<br />
  All macro flags with `<#>` or `[#]` take only numbers as arguments.<br />
  Additionally, if there is no space between the flag `<…>`/`<#>` or `[…]`/`[#]`, you MUST NOT have a space between the flag and the argument passed to it.<br />
  Conversely, if there *is* a space you SHOULD assume the flag needs a space between them.
</Aside>

These are guidelines for packaging projects written in [Nim](https://nim-lang.org).

For the official Nim language documentation, [see here](https://nim-lang.org/documentation.html).

- You SHOULD add (at least!) the following build dependencies to your spec file:
  - <Code code={`BuildRequires: nim`} lang={RPMSpec} inline />
- You SHOULD use our [Nim macros](/contributing/srpm#nim).

In most cases, use `nimble` to download dependencies in <Code code={`%prep`} lang={RPMSpec} inline />,
then <Code code={`%build`} lang={RPMSpec} inline /> with `nim`, e.g.[^1]:

```rpmspec
%prep
%autosetup
%nim_prep

%build
%nim_c src/dive

%install
install -Dm755 src/dive -t %buildroot%_bindir
```

The use of the [`atlas`](https://github.com/nim-lang/atlas) package cloner is also recognized, e.g.[^2]:

```rpmspec
%prep
%autosetup -Sgit

%build
atlas init
atlas rep atlas.lock
%nim_c src/netto
```

# BuildSystem (nimble)

The <Code code={`BuildSystem`} lang={RPMSpec} inline /> RPM feature allows for cleaner spec files and ensures no step is forgotten or mishandled within a declarative build.
To learn more about general <Code code={`BuildSystem`} lang={RPMSpec} inline /> usage in Terra, please see the [Declarative Builds](/contributing/guidelines#declarative-builds) guideline below.

To build declarative nim packages (that use `nimble`) in Terra, we have our own <Code code={`BuildSystem: nimble`} lang={RPMSpec} inline />.

Example spec:

```rpmspec
Name:           umdive
Version:        0.1.5
Release:        1%{?dist}
Summary:        Chroot utility (just like arch-chroot)
License:        MIT
URL:            https://github.com/Ultramarine-Linux/dive
Source0:        %{url}/archive/refs/tags/v%{version}.tar.gz
Requires:       %{_bindir}/chroot
Requires:       %{_bindir}/mount
BuildRequires:  nim
BuildSystem:    nimble
Provides:       dive = %{evr}

%description
%{summary}.

%files
%doc README.md
%license LICENSE
%{_bindir}/dive

%changelog
* Tue Nov 17 2026 Owen Zimmerman <owen@fyralabs.com> - 0.1.5-1
- Adapt to example spec
```
