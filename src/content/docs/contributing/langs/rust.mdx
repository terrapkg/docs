<Aside title="Macro Argument Syntax" type="tip">
  All macro flags followed by `<…>` REQUIRE an argument passed to them.<br />
  All macro flags followed by `[…]` MAY have an argument passed to them.<br />
  All macro flags with `<#>` or `[#]` take only numbers as arguments.<br />
  Additionally, if there is no space between the flag `<…>`/`<#>` or `[…]`/`[#]`, you MUST NOT have a space between the flag and the argument passed to it.<br />
  Conversely, if there *is* a space you SHOULD assume the flag needs a space between them.
</Aside>

These are guidelines for packaging projects written in [Rust](https://rust-lang.org).
If the software you would like to package is available on https://crates.io,
we recommend generating the spec file first using `rust2rpm`[^1],
then modify the spec file to match our packaging guidelines.

# rust2rpm

- Generate the spec file using `rust2rpm name-of-crate`
- Remove the line starting with `Patch:` (and the `.patch` file too) if it exists
- Replace `%{crates_source}` with `%{terra_crates_source}`
- Add `Packager: your name <mail@example.com>`
- Replace `%cargo_prep` with `%cargo_prep_online`
- Remove `%generate_buildrequires` and `%cargo_generate_buildrequires`
- Replace `%cargo_install` with `%terra_cargo_install`, or install files manually with `install`
- Replace `%autochangelog` with a manual changelog entry, in accordance with out [changelog](/contributing/guidelines#changelog) policy.
- Now use anda to build the package, and wait until you see a list of licenses starting with `# ` in the log output, then stop the build
- Use [`format-license`](https://github.com/terrapkg/cli-tools/blob/main/format-license.sh) to format the <Code code={`License:`} lang={RPMSpec} inline /> tag, or use <Code code={`%cargo_license_preamble_online`} lang={RPMSpec} inline /> to output a formatted summary. Paste the final license into <Code code={`License:`} lang={RPMSpec} inline /> in the spec file. The package's source code license(s) SHOULD be specified in <Code code={`SourceLicense:`} lang={RPMSpec} inline />

Your final spec would like something like this:[^2]

```rpmspec
# Generated by rust2rpm 23
%bcond_without check

%global crate joshuto
%global __brp_mangle_shebangs %{nil}

Name:           rust-joshuto
Version:        0.9.9
Release:        1%?dist
Summary:        Terminal file manager inspired by ranger

License:        LGPL-3.0-only
URL:            https://crates.io/crates/joshuto
Source:         %{terra_crates_source}

BuildRequires:  cargo-rpm-macros

%global _description %{expand:
Terminal file manager inspired by ranger.}

%description %{_description}

%package     -n %{crate}
Summary:        %{summary}

%description -n %{crate} %{_description}

%files       -n %{crate}
%license LICENSE
%license LICENSE.dependencies
%doc README.md
%{_bindir}/joshuto

%prep
%autosetup -n %{crate}-%{version} -p1
%cargo_prep_online

%build
%cargo_build

%install
%cargo_install
%{cargo_license_online} > LICENSE.dependencies

%if %{with check}
%check
%cargo_test
%endif

%changelog
* Wed Jul 22 2026 Owen Zimmerman <owen@fyralabs.com>
- Initial commit
```

# BuildSystem (terra_cargo)

The <Code code={`BuildSystem`} lang={RPMSpec} inline /> RPM feature allows for cleaner spec files and ensures no steps are forgotten or mishandled within a declarative build.
To learn more about general <Code code={`BuildSystem`} lang={RPMSpec} inline /> usage in Terra, please see the [Declarative Builds](/contributing/guidelines#declarative-builds) guideline below.

To build declarative rust packages in Terra, we have our own <Code code={`BuildSystem: terra_cargo`} lang={RPMSpec} inline />.

Example spec:

```rpmspec
Name:           cargo-binstall
Version:        1.26.2
Release:        1%{?dist}
Summary:        Binary installation for rust projects
SourceLicense:  GPL-3.0-only
License:        (dep licenses)
URL:            https://crates.io/crates/cargo-binstall
Source:         %{terra_crates_source}
BuildSystem:    terra_cargo
BuildOption(install): %desktop_file_install
BuildRequires:  cargo-rpm-macros
Packager:       Owen Zimmerman <owen@fyralabs.com>

%description
%{summary}.

%install -a
install -Dm644 binstall.metainfo.xml %{buildroot}%{_metainfodir}/binstall.metainfo.xml

%files
%doc README.md
%license LICENSE LICENSE.dependencies
%{_bindir}/cargo-binstall
%{_metainfodir}/binstall.metainfo.xml

%changelog
* Tue Oct 20 2026 Owen Zimmerman <owen@fyralabs.com> - 1.26.0-1
- Initial commit
```

`terra_cargo` section difference notes:
  - <Code code={`%prep`} lang={RPMSpec} inline /> outputs the formatted license text for you to populate the `License:` preamble tag.
  - <Code code={`%generate_buildrequires`} lang={RPMSpec} inline /> uses <Code code={`%terra_cargo_generate_buildrequires`} lang={RPMSpec} inline />, which uses [cargo4rpm](https://codeberg.org/GildedRoach/cargo4rpm) to generate and install build dependencies.
  - <Code code={`%build`} lang={RPMSpec} inline /> uses <Code code={`%cargo_build_crate`} lang={RPMSpec} inline />.
  - <Code code={`%install`} lang={RPMSpec} inline /> uses <Code code={`%terra_cargo_install`} lang={RPMSpec} inline />, which installs all binaries and `.so` files from `target/rpm/` to the appropriate directories.

# Manual

For rust programs not on crates.io, you will need to manually create the spec.
We recommend copying an existing rust spec file (like the one below) as a template. Here's a pretty simple one for reference:[^3]

```rpmspec
%global ver brush-shell-v0.4.0

Name:           brush-shell
Version:        %(echo %ver | sed 's/brush-shell-v//')
Release:        1%{?dist}
Summary:        bash/POSIX-compatible shell implemented in Rust
URL:            https://github.com/reubeno/brush
Source0:        %{url}/archive/refs/tags/%{name}-v%{version}.tar.gz
License:        ((MIT OR Apache-2.0) AND NCSA) AND ((MIT OR Apache-2.0) AND Unicode-3.0) AND (0BSD OR MIT OR Apache-2.0) AND Apache-2.0 AND (Apache-2.0 OR BSL-1.0) AND (Apache-2.0 OR BSL-1.0 OR MIT) AND (Apache-2.0 OR GPL-2.0-only) AND (Apache-2.0 OR MIT) AND (Apache-2.0 WITH LLVM-exception OR Apache-2.0 OR MIT) AND BSD-2-Clause AND (BSD-2-Clause OR Apache-2.0 OR MIT) AND MIT AND (MIT OR Apache-2.0) AND (MIT OR Apache-2.0 OR LGPL-2.1-or-later) AND (MIT OR Zlib OR Apache-2.0) AND MPL-2.0 AND Unicode-3.0 AND (Unlicense OR MIT) AND WTFPL AND Zlib AND (Zlib OR Apache-2.0 OR MIT)

BuildRequires:  cargo-rpm-macros

Provides:       brush
Packager:       Its-J <jonah@fyralabs.com>

%description
brush-shell is a modern bash- and POSIX- compatible shell written in Rust.
Run your existing scripts and .bashrc unchanged
with built-in syntax highlighting and auto-suggestions.

%prep
%autosetup -n brush-%{name}-v%{version}
%cargo_prep_online

%build
%cargo_build

%install
install -Dm755 target/rpm/brush %{buildroot}%{_bindir}/brush
%cargo_license_summary_online
%{cargo_license_online} > LICENSE.dependencies

%files
%{_bindir}/brush
%license LICENSE LICENSE.dependencies
%doc README.md

%changelog
* Sun May 10 2026 Its-J <jonah@fyralabs.com>
- Package brush
```
