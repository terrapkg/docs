<Aside title="Macro Argument Syntax" type="tip">
  All macro flags followed by `<…>` REQUIRE an argument passed to them.<br />
  All macro flags followed by `[…]` MAY have an argument passed to them.<br />
  All macro flags with `<#>` or `[#]` take only numbers as arguments.<br />
  Additionally, if there is no space between the flag `<…>`/`<#>` or `[…]`/`[#]`, you MUST NOT have a space between the flag and the argument passed to it.<br />
  Conversely, if there *is* a space you SHOULD assume the flag needs a space between them.
</Aside>

# General

Haskell packages in Terra MUST follow the [Fedora Haskell Guidelines](https://docs.fedoraproject.org/my/packaging-guidelines/Haskell/), although if using `cabal-rpm`, you SHOULD edit the changelog entry in accordance with our [changelog policy](/contributing/guidelines#changelog), and you MUST add the `Packager:` line.
You may also use a `sed` script to drop dependency versions instead of `cabal-tweak-dep-ver` or `cabal-tweak-drop-dep`, up to you.

`ghc-*` haskell packages (lib packages) SHOULD be placed in `anda/langs/haskell`, with the folder and spec named with `ghc-*`.

# Package Tests

Haskell packages in Terra SHOULD have a `%check` section.

When using `cabal-rpm spec`, if your spec is generated with a header `# testsuite missing deps:`, then you need to install these dependencies locally and regenerate the spec.
If a test dependency is not packaged in Fedora or Terra, you SHOULD package this dependency, in a separate pull request (to ensure all packages build).
