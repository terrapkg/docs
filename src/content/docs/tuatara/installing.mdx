Currently only OpenSUSE Tumbleweed is supported.
If your system releasever is not `tumbleweed` (but compatible with it),
you should replace `$releasever` in the following command with `tumbleweed` manually.
Additionally, you will need to modify the `/etc/zypp/repos.d/tuatara.repo` file
after the release package is installed.

```sh
sudo zypper install --plus-repo 'https://repos.fyralabs.com/tuatara-$releasever' tuatara-release
```

<Aside type="caution">
  Practice caution before running any commands on your system.
</Aside>
